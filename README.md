# CalculaTec

Primeira versão do projeto CalculaTec, um site estático com ferramentas gratuitas de cálculo.

## Arquivos
- `index.html`: estrutura e conteúdo
- `style.css`: identidade visual
- `script.js`: cálculos e interatividade

## Publicação no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `calculatc`.
2. Envie os três arquivos para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`.
6. Salve e aguarde a publicação.

## Observação
Esta primeira versão não coleta dados dos visitantes e não depende de servidor.
